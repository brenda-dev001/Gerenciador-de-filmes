# 🎬 Gerenciador de Filmes


Projeto web para buscar e visualizar filmes utilizando uma API externa.


## 📌 Descrição


Aplicação desenvolvida com HTML, CSS e JavaScript que consome uma API de filmes para exibir informações como título, ano e descrição.


## 🚀 Funcionalidades


- Buscar filmes por nome
- Exibir informações dos filmes
- Salvar filmes em lista
- Interface simples e interativa
- Consumo de API em tempo real


## 🛠️ Tecnologias


- HTML
- CSS
- JavaScript


## 🔌 API utilizada


- API : https://www.omdbapi.com
